# Vicente Vázquez — Portfolio

Personal bilingual portfolio for Full-Stack Development, Product Engineering and AI Solutions roles.

Live site: [portafolio-react-nu.vercel.app](https://portafolio-react-nu.vercel.app/)

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The site uses React and Vite. Motion is implemented with CSS and SVG, with reduced-motion support and no runtime analytics or third-party form scripts.
